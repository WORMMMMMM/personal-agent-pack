# 连接与工具映射

技能中的“读取、查询、创建、更新、回读”描述能力，不固定某个 agent 的工具函数名。接入时查看当前可用工具及 schema，用目标平台的连接器或已配置 MCP 实现这些能力。

- Notion：读取 data source schema；按日期／标题查询并分页；按 schema 创建／更新；按返回 ID 回读。
- Google Calendar：确认账户与日历；限定时间窗查询并分页；创建／增量修改；查询或读取回验；明确循环事件范围。
- 会话：有会话读取工具时使用对应 thread ID；没有时使用用户提供的记录或项目进度来源，说明未覆盖的部分。
- 网页：检索后实际读取一手来源；支持链接和日期核验。

Notion 原生连接器常用 date:时间:start / date:时间:end / date:时间:is_datetime；REST API 则使用 date.start / date.end 嵌套对象。按当前工具 schema 映射，不能把一种工具的参数原样发给另一种。

连接配置可见不代表凭据有效，更不代表可写。只读探测、写入与回读是不同验证层次。没有相应工具时报告具体缺失能力，不推断 OAuth 失效；只有工具返回认证失效时要求重新连接。账户凭据留在各平台授权系统，Hub 不保存凭据。

个人偏好、技能和外部操作权限分别生效。现有用户明确授权在其原范围内继续有效；安装／导出本包本身不发消息、不写日历／Notion、不创建自动化。
