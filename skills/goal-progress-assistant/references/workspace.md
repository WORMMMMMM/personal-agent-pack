# 目标记录参考

先读取随包生成的 resources.json，再核对实时 schema、目标页和子数据库。Hub 只保存位置及规则。

## 状态与结构
- 现有目标数据库字段包括 Name、Status、Importance、Urgency、DDL；运行时核对。
- 常见活跃状态 Not Started、In Progress；暂停 Paused，完成 Succeeded；保留历史和用户陈述。
- 是否免提醒、提醒时间、当前目标值、周期起点从目标页／既有提醒读取，不根据过往目标清单推定。
- 详细学习记录优先写入该目标已有子页；保留父页当前状态、日期历史与原话。

## 每日指标
- 一个目标一个当地日期一行；后续报告合并明确给出的字段，不清空未提及字段。
- 当前减脂数据库字段可能包括记录、日期、体重kg、体重斤、运动、高热量饮食、高热量记录、备注。先读取实际 schema。
- 1kg = 2斤。单位明确时严格使用；省略单位时参考该用户当前记录习惯，说明推断，有实质歧义才询问。
- “没有运动”是明确事实，“未提及”是未知。复选框未勾选不能证明没有高热量饮食；用文字保留未知。
- 目标阈值从活跃目标页读取，不固定为历史数值。
- 饮食周期如仍在使用，读取当前用户约定的长度、各日说明及最新起点，按当地日期差计算 ((D-A) mod 周期长度)+1。仅忠实记录用户约定，不扩展成饮食建议。
- 图表使用真实数值，不填假记录来调整坐标轴。

## 提醒
- 读取现有系列的时间、标题、范围与关联目标。通知标题显示当前有提醒资格的活跃目标。
- 生命周期变更时同步提醒，保留原系列历史；恢复时核对周期和未来实例。
- 没有活跃目标时不保留过期目标名称。
