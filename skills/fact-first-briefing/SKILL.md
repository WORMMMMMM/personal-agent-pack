# 早报与每周深读

读取 [资料导航](../../PROJECT_MAP.md)。先核实时钟、北京时间、请求分支与已有同日完整结果；调度时间从原调度器读取，不从旧会话猜测。

## 日期与去重
- 一次只执行每日简报或每周深读一个分支。每日覆盖生成时刻前24小时，深读覆盖前7天，明确绝对起止时间。
- 自动运行只生成当天，不追补历史；同一天同一分支已完成不得重复。无法确认既往完成状态时说明缺口并优先避免重复。
- 迟于计划时仍使用当天日期，注明实际生成时间；背景可早于覆盖窗口，必须标为背景，不能算新增事实。

## 证据与内容
- 事实优先，宁缺毋滥。一手材料优先；专业媒体用于发现和交叉核对。两篇转引同一通稿不算两个独立来源。
- 每项交代事件日期、证据链接、来源性质、相关性分析与不确定性。区分宣布、生效、执行、演示、真实部署和交付。
- 每日约10分钟阅读：最多3件最重要的新事实；随后具身智能与机器人、国际局势与中国、北京与清华、股票学习。没有可靠重要新增时不凑数。
- 国际部分选2—3个有实质新增的议题，一个主读；证据充分时约占全文40%。主读约500—800字，按新增事实、背景、利益约束、影响机制、待验证问题连贯展开。证据不足则缩短。
- 股票内容用于基础学习，不作个股买卖建议。解释资金流向、收益与风险来源，并核对真实公告或数据。

处理国际议题时读 [选题与解释方法](references/international.md)。历史参考文档帮助学习分析方法，不自动成为事实证据或固定立场。

## 每周深读：机器人与具身智能前沿推荐

目的是给用户推荐值得读的机器人、具身智能文章，让用户了解前沿、保持认知。用户是具身智能方向的博士生，按研究者水平选题和讲解，不做科普式铺垫。只覆盖这个领域；国际局势、北京清华和股票留在每日简报。

- 选 3—5 篇：论文、技术报告、项目页或有实质技术内容的官方博客。以覆盖窗口内发布的为主；更早发布、但本周有实质新进展（开源代码或模型、真机复现、中选重要会议）的可以收，注明原发布日期和本周的变化。
- 选题标准依次是：对领域方向的影响（新范式、新数据或新基准、规模化结论）、证据强度、与具身智能主线的相关性。团队名气和传播热度只作发现线索，不作入选理由。没有够格的不凑数，宁可少推。
- 每篇写清：标题、作者与机构、发布日期、原文链接（优先 arXiv、项目页、官方博客）；解决什么问题、核心方法、关键结果；证据形态，区分真机实验、仿真、演示视频，以及是否开源；局限和存疑之处；为什么值得读，以及建议重点读哪部分。
- 开头用一段话串起本周动向：这几篇共同指向什么、和此前的工作有何不同。只写能从原文支持的联系，推测标为推测。
- 结尾最多列 3 个值得继续跟踪的问题，以及要回答它们需要什么新证据。
- 各篇按推荐优先级排序，第一篇是本周最值得读的。

上一期只用于去重、纠错和观察新增变化。发现旧错误说明原值、修正值、来源和影响。未检索到信息不等于事情没有发生。
