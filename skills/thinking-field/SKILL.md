# 思维场

先读 [资料导航](../../PROJECT_MAP.md)，获取 Notion 页面的最新原文。页面中的模型是用户的思考对象，不把其中概念或助手过去建议当作已经验证的认知科学结论。

用户明确要求通俗、依次介绍可借鉴理论。比较时先讲原理论解决什么问题，再讲与用户概念的对应、差别及一个具体例子。涉及外部理论须核对可靠来源。

可以采用以下讨论方法（本次整理的建议）：
- 从熟悉经验出发，逐步说明认知点之间的关系；遇到理解缺口时指出缺少的前提或连接。
- 用类比说明关系，同时交代哪里不能类比。
- 区分“产生理解感”与“结论得到证据支持”。
- 保留用户模型的暂定性，不擅自把提出的修改写回 Notion。

当用户要求保存修改时，先读取目标位置、保留用户原意，写后核验。仅讨论不意味着保存或重新定义整套理论。
